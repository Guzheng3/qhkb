# 课表类 App 竞品调研（事实笔记）

本文件是课表类产品的公开信息调研结果，供规划书引用。只陈述可核实的公开信息，不做方案设计。

- 访问日期：除单独注明外，全部为 **2026-10-20**（Asia/Shanghai）。
- 来源优先级：产品官网／官方帮助文档 > Apple App Store 中国区页面 > 腾讯应用宝详情页（含开发者、版本、更新时间、下载量）> 用户评论（第三方主观信息，会明确标注）。
- 检索渠道：产品官网、Apple App Store 中国区、腾讯应用宝、必应中国站（cn.bing.com）。必应中国站对中文产品名的检索质量异常（长尾词大量返回无关结果，`site:` 与引号不起作用），华为应用市场搜索页为前端渲染、抓取为空，百度百科返回 403。凡检索无果者一律写"未证实"，不做推测。
- 命名指向不明的对象（星链、课程格子、时光课表）单列说明取证过程，不强行套字段。

## 1. WakeUp课程表

- **产品名与平台**：WakeUp课程表；官方支持 Android、鸿蒙（HarmonyOS NEXT）、iOS 三端，官网自述"1800+ 高校"（https://www.wakeup.fun/ ，2026-10-20）。鸿蒙 NEXT 版单独上架华为应用市场（官网下载入口，同上）。
- **收费模式**：商店页均标免费——App Store 价格 0 元（https://apps.apple.com/cn/app/id1553402284 ，2026-10-20），应用宝标"官方正版免费下载"（https://sj.qq.com/appdetail/com.suda.yzune.wakeupschedule ，2026-10-20）。内购／会员／订阅价格：**未证实**；官方文档把 iCloud 同步、导出日历、更多小组件、上课提醒归入"高级功能"，但未说明是否收费（https://www.wakeup.fun/doc/settings/advance_features.html ，2026-10-20）。
- **课表核心能力**：默认周视图（日期栏 + 左侧时间轴）；支持多课表且各课表配置独立；"课表数据"含一天课程节数、学期周数、当前周、学期开始日期、周日是否为首日；"上课时间"可保存多套时间表（节次时间模板），可取消"每节课时长相同"逐节调时长（https://www.wakeup.fun/doc/settings/schedule_settings.html ，2026-10-20）。课程按"时间段"组织，每个时间段独立设星期几、地点、教师、上下课时间与周数范围；iOS 版没有"日期模式"（按起止日期录入）（https://www.wakeup.fun/doc/add_course.html ，2026-10-20）。单双周／指定周的逐字勾选项：文档只写"周数"设置，**未证实**。
- **录入方式**：教务系统导入 —— 官方文档 1200+ 所（https://www.wakeup.fun/doc/ ，2026-10-20）、官网首页 1800+、应用宝简介 3000+（https://sj.qq.com/appdetail/com.suda.yzune.wakeupschedule ，2026-10-20）、App Store 简介 2000+（https://apps.apple.com/cn/app/id1553402284 ，2026-10-20），四处口径互不一致；HTML 文件导入、Excel/CSV 模板导入（https://www.wakeup.fun/doc/import_from_file.html ，2026-10-20）；分享码导入（App Store 与应用宝简介，2026-10-20）。截图识别：**未证实**。
- **提醒能力**：上课前自动提醒、提前时间可自定义（App Store 简介）；"上课提醒"同时在"高级功能"清单内（官方文档，2026-10-20）。系统闹钟形式的叫醒：**未证实**。
- **桌面小组件与系统集成**：Android 4 种（今日课程／近日课程／一周课程／日视图），鸿蒙另加 2 张图标上划卡片，iOS 5 种；其中 Android 的"一周课程""日视图"支持样式自定义与切换课表；官方明确提示要允许后台自启与后台运行才能保证小组件正常（https://www.wakeup.fun/doc/widget.html ，2026-10-20）。灵动岛／实况窗／厂商"岛"类适配：**未证实**。
- **天气或附加能力**：App Store 简介提到"日程管理"等内置小工具；官网友情链接为记账类产品"钱迹"（非同产品）。天气功能：**未证实**。
- **共享或多人协同**：仅见"分享码导入"（同学间课表分发）；是否支持持续同步的双向协同：**未证实**。
- **可借鉴点**：多套节次时间模板 + 逐节时长覆盖；同一份课表在三端都提供多尺寸桌面小组件；录入通道做成"教务 + 文件 + 分享码"三条并行；官方帮助文档把每个设置项写全，降低答疑成本。
- **短板与限制**：应用宝显示 20.0 万下载、评分 4.8 并标注"无广告"（2026-10-20），而 iOS 端 2776 个评分的均分仅约 1.7（App Store，2026-10-20），两端口碑差异显著；高校适配数量对外四个口径不一致，说明对外数字未经统一维护；iOS 功能少于 Android/鸿蒙（无日期模式，小组件样式等归入"高级功能"）。

- **桌面小组件与系统集成**：桌面小组件（App Store 与应用宝简介，2026-10-20）。"岛"类适配：**未证实**。
- **天气或附加能力**：官方考试时间同步（版本说明）、成绩查询与校友求助／语音互动（均为应用宝用户评论提及，第三方主观）。天气：**未证实**。
- **共享或多人协同**：**未证实**。
- **可借鉴点**：把"全校官方考试时间"这类校内强需求与课表打通，做出课表之外的日程价值；用户规模大（应用宝 1807.2 万下载，2026-10-20）。
- **短板与限制**：评分偏低——应用宝 4.2，iOS 14882 个评分均分约 2.93（2026-10-20）；广告投诉集中（第三方用户评论）；教务解析依赖人工适配学校（纠错记录里的"导课真的拉"为用户评论）。
